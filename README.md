This is a library manager system for storing books. Books can be added and searched by title or author.

book.py holds the book object.

library_manager.py holds the front facing program as well as the methods for executing user commands.

The program is run through library_manager.py.

Features:

Add a new book to the library

Print the contents of the library

Find a book through title or author using the specified keyword

Output:

Gives the library manager menu and prompts for user input.
